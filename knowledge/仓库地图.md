# 仓库地图

## 方向一：SM9 + 生物特征 Kerberos

- 核心模块（`方向一/core/`）：fuzzy_extractor（模糊提取）、stable_bits（稳定位）、sm9_engine（SM9）、did（DID）、kerberos_enhanced（Kerberos 增强）、circuit_breaker（熔断）、kdc_tee（模拟 TEE）、audit_logger（审计）
- 实验入口：`方向一/实验/实验一~五/实验一~五.py`
- 输出：`方向一/实验/实验X/结果/`（独立 CSV）
- 禁止修改：核心安全流程、SM9 实现、模糊提取算法、DID/ST 语义
- 可修改：实验脚本、日志、参数配置、统计逻辑

## 方向二：SM9 国密 P2P VPN

- 核心模块（`方向二/core/`）：st_ticket（ST 票据）、relay（中继准入）、nat_layer（NAT 打洞）、tunnel（SM4 隧道）、shaping（流量整形）、sm9_engine、did、authorization（代理授权）
- 实验入口：`方向二/实验/实验零~四/实验零~四.py`
- 输出：`方向二/实验/实验X/结果/`
- 禁止修改：ST 语义、KDC 核心、SM9 实现、代理授权流程
- 可修改：实验脚本、基线对照逻辑、指标统计

## 方向三：SM9 双 DID MCP

- 核心模块（`方向三/core/`）：mcp_server（四步验证）、mcp_agent（双签名链）、claims_checker（权限匹配）、st_ticket、sm9_engine、oauth_baseline / noauth_baseline（基线）
- 实验入口：`方向三/实验/实验零~四/实验零~四.py`
- 输出：`方向三/实验/实验X/结果/`
- 禁止修改：MCP 总体架构、四步验证流程、双签名链语义
- 可修改：实验脚本、基线配置、性能统计

## 共享语义（三方向一致）

SM9 引擎 / DID / ST 票据 / 审计 / 公共工具（common）在三方向中语义一致，修改共享模块需按「变更控制」Level 2 先汇报。
