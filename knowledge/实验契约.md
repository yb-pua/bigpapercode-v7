# 实验契约

## 通用规则

1. 不改变核心安全协议、既有接口、默认算法参数（除非任务明确要求）
2. 所有实验必须可重复
3. 所有结果必须带时间戳和 commit hash
4. CSV 不允许覆盖其他实验
5. 不允许硬编码实验结果
6. 不允许将模拟结果标记为真实结果
7. 所有实验必须记录环境
8. 所有实验输出必须可追溯到脚本

## 方向一参数

- k（投票张数）：2 / 3 / 4 / 5（主配置 5）
- dimension：512（InsightFace）/ 128（dlib 消融）
- 纠错码：RS(255,191,t=32)，max_correct=28（异人安全边际）
- dataset：LFW；random_seed：20260817；repeat：≥1
- 指标：KRR / FAR / FRR / EER / AUC

## 方向二参数

- replay_count：≥1000（契约要求，非 100）
- node_count / concurrency：按实验设计
- 指标：admission latency / p50 / p95 / throughput / RTT / CPU / memory

## 方向三参数

- baseline：NoAuth / OAuth / Proposed
- attack：replay / tamper / impersonation / privilege escalation / caller confusion
- 指标：attack success rate / reject rate / latency / message size / audit completeness

## 输出要求

每实验独立目录，含：脚本、结果 CSV、日志、元数据（commit/timestamp/参数/seed/样本量/重复次数）。
