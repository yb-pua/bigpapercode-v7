# 系统说明

论文：基于 SM9 与生物特征的零信任 P2P 网络安全机制研究。

三方向递进关系：

| 方向 | 定位 | 机制 |
|---|---|---|
| 方向一 | 核心创新 | SM9 + 生物特征模糊提取的 Kerberos 身份认证（生物门控的用户 DID + 非存储式模板 + 前置验签 + 熔断） |
| 方向二 | 机制递进 | 基于 ST 票据的 P2P VPN 安全通信（设备 DID + ST 准入 + 代理授权 + 隧道整形） |
| 方向三 | 应用验证 | 面向 MCP 云服务的访问控制（双 DID + 双 ST + 双签名链 + 四步验证） |

统一语义（三方向一致）：
- DID = 身份标识
- ST = 授权票据
- ticket_id = 审计关联键

端到端路径（实验 H 目标）：
Human → 生物认证 → 生物门控的用户 DID → KDC → ST → 设备 DID → P2P 准入 → Agent DID → 双签名 → MCP → 工具 → ticket_id 审计。
